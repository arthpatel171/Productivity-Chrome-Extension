# Productivity-Chrome-Extension

Offline workspace for scheduling tasks, tracking time, and organizing notes-all stored locally in your browser.

## Features

- Create, edit, complete, and delete scheduled tasks
- Add breaks to task schedules
- Monitor active tasks and view task time by calendar and color\
- Get insight of how you spent your day
- Track elapsed time with a stopwatch and laps
- Run countdown timers
- Create rich-text notes with multiple text boxes
- Paste and resize images inside notes
- Reorder text boxes
- Browser notifications and task reminders
- Import and export workspace data
- Light and dark themes
- Fully local storage with no account required

## Installation

1. Download or clone this repository.
2. Open `chrome://extensions` in Google Chrome or `edge://extensions` Microsoft Edge.
3. Enable **Developer mode**.
4. Select **Load unpacked**.
5. Choose the project folder.
6. Open the extension from the browser toolbar.

## Usage

- Use **Calendar** to schedule and manage tasks.
- Use **Notes** to create and format text boxes or paste images.
- Use **Time tools** to use the stopwatch and countdown timer.
- Use **Import/Export** to back up or restore workspace data.

## Privacy and Storage

This extension stores notes, tasks, timers, and settings in Chrome's local extension storage. It does not require an account or send workspace data to a server.

## Development

Load the repository as an unpacked extension after making changes. Reload the extension from `chrome://extensions` to test updated code.

## Technologies

- HTML
- CSS
- JavaScript
- Chrome Extension Manifest V3
- Chrome Storage, Alarm, and Notification APIs
