Only 2 sections of the extension can trigger popups, which are the time tools and calendar.

The time tools only gives a popup when a timer hits 0. 
The popup only displays on the active page the user is on, and no where else.
That is the only condition that the time tools can trigger a popup.

The other section is the calendar that can trigger a popup.

Also, when a scheduled task for later start time arrives, a popup appears, as well as the end time for that task
